## ✨ Features

- **150 Full-Fidelity Design Systems**: Curated specifications covering enterprise SaaS, developer tools, AI assistants, luxury brands, creative styles, and modern UI paradigms.
- **Zero Runtime Dependencies**: Every showcase is built strictly with semantic HTML5, modern CSS3 custom properties, and lightweight vanilla JavaScript. No node_modules, bundlers, or heavy frameworks required.
- **Complete `DESIGN.md` Specifications**: Every system includes a standardized document detailing visual theme, atmosphere, complete color scales, typography hierarchies, elevation/shadows, component blueprints, and design do's and don'ts.
- **Self-Contained Interactive Previews**: Each system includes a standalone `<name>.html` file showcasing live components—buttons, inputs, navigation, badges, hero sections, cards, modals, and color swatches.
- **Copy-Paste Design Tokens**: Every HTML showcase maps design tokens directly to native `:root` CSS custom properties (`--color-*`, `--font-*`, `--space-*`, `--radius-*`, `--shadow-*`).
- **Autonomous Agent & LLM Optimized**: Standardized `DESIGN.md` token architecture makes this repository an ideal ground-truth library for prompt-engineering AI models to write brand-consistent UI code.
- **Fully Responsive & Accessible**: Responsive grid layouts and accessible contrast ratios tested across modern browser viewports.

## 🚀 Installation

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Apple Safari, Microsoft Edge).
- (Optional) [Git](https://git-scm.com/) to clone the repository.
- (Optional) [Python 3](https://www.python.org/) or [Node.js](https://nodejs.org/) for running a local development server.

### Setup Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/H0NEYP0T-466/Design-Systems.git
   cd Design-Systems
   ```

2. **Launch a local preview server:**
   ```bash
   # Using Python 3
   python3 -m http.server 8000

   # Or using Node.js
   npx serve .

   # Or simply open any .html file directly in your browser:
   # double click on <folder>/<folder>.html
   ```

3. **Visit the preview:**
   Navigate to `http://localhost:8000/<system-name>/<system-name>.html` (e.g., `http://localhost:8000/kraken/kraken.html`).

## ⚡ Usage Examples

### 1. Previewing Showcases Locally

Every folder contains a fully rendered, self-contained showcase illustrating the design system in action:

```bash
# Open the Stripe design system showcase in Google Chrome (Linux)
google-chrome stripe/stripe.html

# On macOS
open stripe/stripe.html

# On Windows
start stripe/stripe.html
```

### 2. Extracting CSS Custom Properties (Design Tokens)

Easily extract and drop tokens into your frontend framework (React, Vue, Svelte, Tailwind, or Next.js). Every `<name>.html` declares its design tokens at the top inside `:root`:

```css
/* Example extracted from linear-app/linear-app.html */
:root {
  --color-bg: #08090a;
  --color-surface: #121316;
  --color-surface-hover: #1c1d22;
  --color-border: rgba(255, 255, 255, 0.08);
  --color-accent: #5e6ad2;
  --color-accent-hover: #6f7ce8;
  --color-text-primary: #f7f8f8;
  --color-text-secondary: #8a8f98;
  --font-family-sans: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 12px;
}
```

### 3. Empowering AI Coding Agents & LLMs

Pass any `DESIGN.md` specification directly into an LLM system prompt (e.g., Claude 3.7 Sonnet, GPT-4o, Gemini 2.5 Flash) to generate brand-aligned frontend code:

```text
"Please build a user settings page adhering strictly to the design tokens,
color palette, typography rules, and component constraints specified in
Design-Systems/kraken/DESIGN.md."
```
