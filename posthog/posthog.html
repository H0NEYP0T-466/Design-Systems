HogQL Query Engine

Query your analytics like a real database

PostHog allows direct SQL querying on top of raw ClickHouse events using Source Code Pro.

query_funnel_retention.sql — HogQL ClickHouse Dialect Source Code Pro 14px 
-- Query active power users who hovered over orange CTA elements
SELECT
    distinct_id,
    count(*) AS total_interactions,
    avg(properties.$duration) AS avg_session_sec,
    max(timestamp) AS last_seen
FROM events
WHERE event = '$pageview'
  AND properties.$current_url LIKE '%posthog.html%'
  AND timestamp >= now() - INTERVAL '7 DAY'
GROUP BY distinct_id
HAVING total_interactions > 12
ORDER BY total_interactions DESC
LIMIT 5;
