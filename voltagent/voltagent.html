FEATURE 01 • ACTIVE ORCHESTRATION

Deterministic Tool Calls

Type-safe JSON schema generation with runtime validation guards against hallucinated parameters across any LLM model.

const agent = new VoltAgent({
  model: 'claude-3-7-sonnet',
  tools: [codeSandbox, sqlQuery],
  telemetry: true
});
FEATURE 02 • RUNTIME MEMORY

Sub-millisecond Vector Memory

Embedded vector stores with dual L1 cache and persistent SQLite backends ensure agent conversations survive pod restarts.

await agent.recall({
  namespace: 'user_prefs',
  similarityThreshold: 0.89
});
FEATURE 03 • EVALUATION

Real-time Swarm Telemetry

Inspect token consumption, reasoning traces, latency percentiles, and multi-agent handshake messages in real-time.

// Output stream telemetry
agent.on('swarm:step', (event) => {
  console.log(event.step_index, event.cost);
});
