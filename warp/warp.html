Block-Based Paradigm

Commands grouped into interactive blocks

Instead of endless scrollback, Warp treats each terminal command and its output as an individual object you can copy, share, and debug.

Block Navigation

Jump effortlessly between command executions with keyboard shortcuts. Select, copy, or rerun entire blocks in isolation.

cmd+shift+c to copy block

AI Command Search

Convert plain English descriptions into complex bash, zsh, or fish one-liners directly inside your active shell buffer.
