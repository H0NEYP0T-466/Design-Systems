Zero Cloud Serialization: Runs inside your shell session

Unlike SaaS browser copilots that stream your entire proprietary codebase to remote hosted backends, OpenCode runs as a native single binary on Linux and macOS. It reads directly from your filesystem and communicates via your own local API tokens or Ollama inference daemon.

Core Architecture Invariants

Disciplined engineering principles baked into every line of code.

> AST-Aware Diffs Treesitter integration prevents invalid syntax before writing changes to disk. Syntactic boundaries are respected on every patch.
> Sub-process Sandbox All commands run in an isolated cgroup/chroot environment with bounded memory and disk quotas to protect production environments.
> Bring Your Own LLM Pluggable backend support for Claude 3.5 Sonnet, GPT-4o, DeepSeek-V3, or local models running via Ollama and vLLM.
> Instant Git Rollback Every automated action creates a recoverable git ref checkpoint. One keypress immediately reverts unwanted refactoring trees.
